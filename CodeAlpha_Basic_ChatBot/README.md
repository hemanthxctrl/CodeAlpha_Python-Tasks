# 🤖 Basic Rule-Based Chatbot 

# 📌 Project Overview 

This chatbot takes text input from the user and returns a predefined reply based on pattern matching. 

It runs in the terminal and keeps chatting in a loop until the user says goodbye.


## 💬 Supported Inputs & Replies

| User Says                         | Bot Replies                                                                 |
|----------------------------------|----------------------------------------------------------------------------|
| hello / hi / hey                 | Hi there! How can I help you today?                                         |
| how are you                      | I'm doing great, thanks for asking! How about you?                          |
| what is your name                | I'm ChatBot, your friendly rule-based assistant!                            |
| help                             | I can respond to greetings, questions, and goodbyes!                        |
| tell me a joke                   | Why do programmers prefer dark mode? Light attracts bugs!                   |
| thanks / thank you               | You're welcome! Anything else I can help with?                              |
| good morning                     | Good morning! Hope your day is off to a great start!                        |
| good night                       | Good night! Sleep well!                                                     |
| bye / goodbye                    | Goodbye! Have a wonderful day!                                              |
| (anything else)                  | Hmm, I didn't catch that. Try 'hello', 'how are you', or 'bye'!             |

## 🚀 How to Run

- Install python3.x in your laptop
- Run the chatbot - python chatbot.py
