# Stock Portfolio Tracker 📈


A beginner-friendly Python project that lets users build a stock portfolio, calculate total investment value, and optionally export results to .txt or .csv.



#  Concepts Used 📊

- Python Dictionaries
- Loops (while loop)
- Conditional Statements
- Input/Output Handling
- Basic Arithmetic
- File Handling (CSV & TXT)



# How to Run  🚀

- Insatll python(if not installed)  
- In terminal type : python stock_tracker.py


#  Example Usage 📝

## Stock Portfolio Tracker

Available stocks: AAPLE, TESLA, GOOGLE, MSFT, AMAZON
Enter stock name (or 'done'): AAPL
Enter quantity: 2

Enter stock name (or 'done'): TSLA
Enter quantity: 1
Enter stock name (or 'done'): done


#  Output 📈
##  Portfolio Summary:

AAPL -> 2 shares × $180 = $360

TSLA -> 1 shares × $250 = $250

💰 Total Investment Value: $610
